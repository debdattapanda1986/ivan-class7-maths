# CBSE Class 7 Mathematics — 3-Set CBT

Separate Mathematics CBT. This does NOT replace the Science repository.

## Sets
- Set A: 60 marks
- Set B: 60 marks
- Set C: 60 marks
- 30 minutes per attempt
- 36 questions per set; total = 60 marks

## Syllabus
Based on the uploaded GIIS Grade VII Half-Yearly syllabus:
1. Integers
2. Fractions
3. Decimals
4. Rational Numbers
5. Powers and Exponents
6. Algebraic Expressions
7. Simple Linear Equations
12. Symmetry
17. Collecting/Organizing Data

## Files
- index.html
- style.css
- script.js
- questions.js

Upload these four files to a NEW GitHub repository, for example:
`ivan-class7-maths`

Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

The CBT is designed for home practice. Because answers are client-side JavaScript, it is not a secure high-stakes examination system.
